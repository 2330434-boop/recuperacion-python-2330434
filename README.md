# Recuperación Python - Proyecto de Empleados

Sistema de gestión y cálculo de nómina de empleados desarrollado en Python.

## Estructura del proyecto

- `src/recuperacion_python_2330434/`:
  - `models.py`: Modelo de datos `Empleado`.
  - `services.py`: Lógica de negocio y gestión de empleados.
  - `main.py`: Menú interactivo en consola.
  - `test_services.py`: Pruebas unitarias para las funciones del sistema.
- `pyproject.toml`: Configuración del proyecto y dependencias.
